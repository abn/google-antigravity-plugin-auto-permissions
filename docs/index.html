          Security Governance
          
4-Tier Permission Taxonomy

          

            How the security gate routes candidate operations to maximize agent velocity without sacrificing human control.
          

        


        

          
          

            

              
1. ALLOW

              🟢 ZERO FRICTION
            

            

              
Safe, non-destructive operations that strictly match stated developer intent (e.g. running unit tests, formatting code, reading workspace files).

              

                
Agent Behavior

                
Tool executes immediately with sub-millisecond fast-path or cached authorization.

              

            

          


          
          

            

              
2. SOFT_DENY

              🔴 SELF-CORRECTION
            

            

              
Non-malicious actions that diverge from the active prompt scope (e.g. unrequested branch deletions, modifying unprompted files).

              

                
Deny-and-Continue Loop

                
The agent receives a scope explanation, self-corrects without crashing, and stays within bounds.

              

            

          


          
          

            

              
3. ASK

              🟡 HUMAN ESCALATION
            

            

              
High-impact, sensitive actions (e.g. production deployments, database migrations, cloud credentials, network tunnels).

              

                
Interactive Modal

                
Execution pauses and presents an interactive confirmation dialog directly to the developer.

              

            

          


          
          

            

              
4. HARD_DENY

              🔴 SECURITY BLOCK
            

            

              
Hostile, destructive, or exfiltrative actions (e.g. credential extraction, reading ~/.ssh, destructive wipes rm -rf /, prompt injection).

              

                
Permanent Termination

                
Operation is permanently blocked and an incident record is logged to the session audit trail.

The Decoupled Classifier

              

                The safety classifier runs as an isolated decision gate blinded to the agent's internal chain-of-thought (CoT) and raw tool outputs. It observes strictly authentic user prompts, candidate tool calls, and workspace roots.
              

              

                
IPI Immunity

                
Blinding eliminates Indirect Prompt Injection attacks originating from untrusted web pages or repositories.

              

            


            

              
KV-Cache Prefix Stability

              

                The classifier prompt enforces strict top-to-bottom volatility layering: static system instructions $\rightarrow$ workspace roots $\rightarrow$ monotonic chronological user turns ([Turn 0], [Turn 1]) $\rightarrow$ dynamic tail.
              

              

                
Cache Retention

                
Maintains >93% prefix cache hits within turns and >51% across multi-turn handoffs.

Hierarchical Static ACL Engine

            

              Static rules evaluate across 4 hierarchical scopes with strict Deny > Ask > Allow precedence. Matching static rules execute with sub-millisecond latency (0.1ms) with zero API calls.
            


            

              

                .agents/auto-permissions.json (Project Scope)
                
              

              
{
  "permissions": {
    "allow": [
      "command(git status*)",
      "command(git diff*)",
      "command(git log*)",
      "command(uv run --frozen ruff *)",
      "command(uv run --frozen pytest *)",
      "command(gh pr *)"
    ],
    "deny": [
      "command(rm -rf /.*)"
    ]
  },
  "custom_guidelines": [
    "Treat read-only inspection operations on *.test.internal as safe."
  ]
}

            

          

        


        
        

          

            
Bring Your Own Model (BYOM) Recipes

            

              Configure the plugin to use Google Gemini, Anthropic Claude, OpenAI GPT-4o, or local GPU inference backends (Lemonade, vLLM, Ollama):
            


            

              

                Local GPU (Lemonade / vLLM)
                
              

              
python3 skills/auto-permissions-configure/scripts/configure_permissions.py \
  --scope project_local \
  --provider openai \
  --model Gemma-4-26B-A4B-NoThinking-qat-MTP \
  --endpoint-url "http://localhost:13305/v1/chat/completions" \
  --api-key-env LEMONADE_API_KEY

            


            

              

                Anthropic Claude 3.7 Sonnet
                
              

              
python3 skills/auto-permissions-configure/scripts/configure_permissions.py \
  --scope global \
  --provider anthropic \
  --model claude-3-7-sonnet-20250219
